# ADR-013 — Prix de location non affichés

- **Statut** : Acceptée
- **Sources** : `docs/specs/technique-v2.md` §15, `docs/plan/commits.md` §13

## Décision

La Fiche titre affiche « Location » ou « Achat » sans montant.

## Options écartées

Partenariat JustWatch dès la v1 ; collecte maison

## Raison

TMDB ne fournit pas les prix ; un partenariat est commercial.

## Revoir si

Un accès aux prix devient possible à coût raisonnable.
